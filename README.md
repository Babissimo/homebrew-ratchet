# Babissimo/homebrew-ratchet

The Homebrew tap for [Ratchet](https://github.com/Babissimo/ratchet), a macOS menu-bar time tracker
for FreeAgent.

```bash
brew install babissimo/ratchet/ratchet
```

Upgrade with `brew upgrade ratchet`. Ratchet quits during an upgrade, so open it again afterwards.

`scripts/release.sh` in the Ratchet repository sets the cask's `version` and `sha256` on each
release. Anything else in the cask is edited here.
